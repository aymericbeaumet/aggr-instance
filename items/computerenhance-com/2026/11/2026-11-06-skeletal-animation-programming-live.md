For a few weeks, I will be appearing on Maria Beketova’s channel for some good old-fashioned animation coding.

Back around the turn of the millennium, I spent several years writing animation code for game engines. The code was [used in a large number of titles](https://www.radgametools.com/granny/customers.html), so I got a lot of practice designing mesh and skeletal animation systems that could handle a wide variety of engine requirements.

It’s been two decades since I’ve done this kind of work. Perhaps it’s time for a trip down memory lane?

Maria Beketova is a friend of mine who does Vulkan/C++ engine development streams, and she just so happens to be implementing skeletal animation right now. So, for the next few weeks, I’ll be playing programming assistant and we’ll see just how much about this kind of programming I can remember!
