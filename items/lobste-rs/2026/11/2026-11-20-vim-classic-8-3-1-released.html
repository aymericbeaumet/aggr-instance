[2026-11-20]

I'm proud to announce the second release of Vim Classic, Vim Classic 8.3.1, a stable, long-term support fork of the ubiquitous text editor, maintained without the assistance of generative AI tools.

For more information about the motivations for this fork, please read this blog post.

This release includes applicable Vim patches up to Vim 8.2.3237, including numerous bug fixes, minor features, and compatibility improvements for Vim plugins. This release also removes Python 2 support from Vim Classic.

Vim Classic is charityware, much like Vim, and we are happy to continue supporting Bram's passion of providing for children in need in Uganda. Switching from Vim to Vim Classic would be an opportune moment for you to make a donation!
