I'm proud to announce the second release of Vim Classic, Vim Classic 8.3.1, a stable, long-term support fork of the ubiquitous text editor, maintained without the assistance of generative AI tools.

For more information about the motivations for this fork, please read [this blog post](https://drewdevault.com/2026/03/25/2026-03-25-Forking-vim.html).

This release includes applicable Vim patches up to Vim 8.2.3237, including numerous bug fixes, minor features, and compatibility improvements for Vim plugins. This release also removes Python 2 support from Vim Classic.

Vim Classic is charityware, much like Vim, and we are happy to continue supporting Bram's passion of providing for children in need in Uganda. Switching from Vim to Vim Classic would be an opportune moment for you to [make a donation](https://www.kuwasha.net/)!

Last, but not least, let me extend a big "thanks!" to everyone who jumped in to enthusiastically test Vim Classic, provide feedback, and contribute many patches and backports to get this release done.

Happy editing!
