We’re introducing the Admin plugin for [ChatGPT Work](https://chatgpt.com/?openaicom_referred=true) and [Codex](https://chatgpt.com/codex/?openaicom_referred=true) —a faster, easier way to analyze workspace information, update settings, and act on requests. In one conversation, admins can ask a question, explore the details, make an authorized change, and confirm the result—without writing complex prompts or switching between tools.

Managing a growing workspace often means moving between analytics, settings, and reports to understand issues and take action. This makes routine admin work slower and harder to complete consistently. By bringing admin analytics and supported actions together, the Admin plugin helps teams keep growing workspaces secure, productive, and within budget.

## Helping admins manage growing workspaces

With the Admin plugin, admins can complete their day-to-day tasks directly from ChatGPT Work and Codex, including but not limited to:

- **Understand adoption and usage.** Review activity and credit usage across ChatGPT Work and Codex, identify where additional enablement may help and when members or groups are approaching credit limits.

- **Manage members and groups.** Add or remove members, update groups, and complete routine onboarding, offboarding, and team changes.

- **Manage access and permissions.** Review effective permissions, diagnose access issues, and control feature or model access by role or group.

- **Manage usage limits and spending requests.** Adjust limits for members groups, and workspaces, review requests against current usage, and approve or deny them with context.

## Automate recurring admin workflows

Admins can also use the Admin plugin to automate recurring checks and high-volume requests—without custom engineering. These automations reduce manual monitoring, apply policies more consistently, and let admins focus on decisions that require their judgment.

For example, the plugin can route pending usage requests to Slack or Microsoft Teams, where authorized reviewers can approve or deny them within the tools they already use. It can also monitor feature-access requests and automatically grant access when they meet predefined criteria, while routing exceptions for review. Admins remain in control throughout, and each workflow confirms when requested changes have been applied.

## Scale administration with existing controls

The Admin plugin works within each user’s existing role and permissions; it does not grant broader access. Behind each request, the plugin maps the admin’s instructions to the appropriate supported read or write action and returns a structured result. It makes Admin Console capabilities available to ChatGPT Work and Codex as permission-aware tools, while honoring workspace policies and approval requirements.

For each change, admins can see what they requested, whether the action completed, and what changed. They can review actions with broader impact before those actions are applied.

## How OpenAI’s IT team uses ChatGPT Work and Codex

At OpenAI, the Admin plugin changes the first step of workspace administration for the IT team. With the plugin, the team can simply ask questions to drill into the data, and generate reports and insights.

> “The value is far beyond faster reporting. The Admin plugin connects the question to the next supported action, whether that is checking someone’s effective permissions, updating a group, changing a usage limit, or reviewing a spending request. It gives admins a faster way to understand what is happening and take action, while preserving the same permissions and controls we already use.”

— Kunal Malik, Head of Global IT, OpenAI

The Admin plugin is one example of a broader shift in how OpenAI’s IT team uses ChatGPT Work and Codex. OpenAI’s IT team uses these tools to bring the relevant context and workflows into one place.

- In Slack, a ChatGPT Work agent handles employee IT requests, triages and actions support tickets, retrieves context, checks approved policies, completes supported tasks, and escalates exceptions. At the time of reporting, deployed workflows resolved about ~45% of ticket volume

- ChatGPT Work made it possible to turn support ticket data and history into operational health dashboards, giving IT continuous visibility into service performance. That visibility helped eliminate the backlog and changed how the team operates. Instead of reacting to service issues, the team now uses live data to set priorities and plan for demand, even as support volume roughly doubled.

## Install the Admin plugin for ChatGPT Work

Getting started with the plugin in a few simple steps. First, enable the plugin in ChatGPT workspace settings, then install it from the Plugins directory in ChatGPT Work on the web or desktop app. Once installed, admins can manage day-to-day workspace tasks faster and more consistently.
