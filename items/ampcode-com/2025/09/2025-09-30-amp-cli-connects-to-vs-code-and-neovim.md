You can now connect the [Amp CLI](https://ampcode.com/manual#getting-started-command-line-interface) to VS Code and Neovim.

This allows Amp to access your current file, selected text, and diagnostics. It also enables Amp to edit files directly through your IDE.

All that's required is the latest version of the Amp CLI, and either the [Neovim plugin](https://github.com/ampcode/amp.nvim) or the [Amp VS Code extension](https://marketplace.visualstudio.com/items?itemName=sourcegraph.amp). Then you can run `amp --ide` from your project root and the CLI will connect to the IDE in the current workspace.
