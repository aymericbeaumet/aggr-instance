**Update (2026-01-13):** Forking has been removed as an explicit action. Instead, create a new thread and mention the original thread by URL or ID.

Click on *Fork* to create a new thread containing all messages prior to this point. Forked threads have a backlink to the original thread.

You can use it to take the same thread into different directions. For example, to explore alternative implementations or asking questions while you wait for the current task to finish.
