[Discoverable Servers](https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types) are the most public spaces on Discord, with at least 1,000 members. Their admins chose to list them in Server Discovery so anyone can join them, no invite link needed.

Discussions in Discoverable Servers will soon be easier to find when you search the web, so you can find the answer you’re looking for and step straight into the conversation on Discord. Admins and members can decide if and how their content is shared, and those controls start rolling out today, ahead of any changes.

**TL;DR:**

- **Help people find your community with Server Web Pages.** A Server Web Page is a page on the web that describes a Discoverable Server, so people can decide whether they want to join. Starting November 16, 2026, all Discoverable Servers will have a Server Web Page. These pages may also display summaries of discussions happening in public channels (those visible to everyone in the server), to give a better sense of what people are talking about. Some messages from public channels may show on Server Web Pages and in web search beginning in mid-December 2026. The rollout is gradual, so it may be a few weeks before the first messages start appearing on the web.
- **Server admins can opt channels out starting today, before anything goes live on November 16, 2026**. Controls for admins are in Server Settings > Web Presence. You can choose which channels take part, or opt all channels out. If you don’t change anything, public channels stay on, and your Server Web Page goes live on November 16, 2026, if you don't already have one.
- **Users have control over whether their messages are shown.** If you'd rather your messages weren't shown, you can turn that off starting today in [User Settings > Data and Privacy](https://discord.com/settings/data-and-privacy), before messages start rolling out in mid-December 2026 (or anytime after). One setting covers Channel Messages in every Discoverable Server. Channel Summaries are generated separately, from broader channel topics, and will still appear on Server Web Pages unless admins choose to turn them off. Usernames and avatars won't be shown alongside messages on Server Web Pages
- **Private servers, DMs, and GDMs are always private and not included in these changes.** These changes are limited to Discoverable Servers.

## **How servers work today**

Over the years, Discord has built different kinds of spaces, so every group can decide how big the party gets and who can find it:

- **Most servers are small, private spaces.** They're meant for you, your friends, and nobody else.
- **Community Servers are for bigger groups**, with the tools to handle a crowd. Though someone still has to send you an invite link.
- **Discoverable Servers are the most public spaces on Discord**. To qualify, a server needs at least 1,000 members, has to be at least eight weeks old, and must meet [activity and safety requirements](https://support.discord.com/hc/en-us/articles/360030843331-Enabling-Server-Discovery). Anyone can find and join them, no invite link needed. **Today’s announced features only apply to this type of server.**

![A comparison chart re-stating the differences between Discoverable, Community, and Friend servers. ](https://cdn.prod.website-files.com/5f9072399b2640f14d6a2bf4/6ad923edb249958c3f1c29fb_73500aef.png)

Today, there are more than 63,000 Discoverable Servers, spanning communities from speedrunning to language learning to niche corners of every fandom. People find their way into communities they'd never have stumbled across otherwise. Until now, that's all being Discoverable meant.

## **Why this matters**

Server Discovery was built for finding servers, not answers. Ever wanted to look up tricks for a faster speedrun? Or whether a powerful item is worth grabbing, or if it will completely ruin your build? Someone has almost certainly already answered it in a channel somewhere, in one of 63,000 Discoverable Servers. It can just be hard to find.

Prior to Discord's launch, message boards were common, ranging from community-driven forums to official ones run by game studios. These message boards excelled at hosting long-form, structured conversations about helping people, theory crafting, and more. While they still exist today, many have moved into Discord servers. This has led to valuable information being locked in Discord conversations, inaccessible to the wider internet. We want to fix this.

By giving admins the option to make certain channels discoverable from the web, we can help more people find and benefit from the knowledge shared in Discord communities.

We expect this to help different types of communities in various ways:

- For fandoms, you can make specific channels an easy-to-find resource that answers the top questions new players ask.
- For content creators, you can more easily promote events and new content drops.
- For indie game developers, you can use public channels, including forums, to share updates and wiki-style information about your games.

## **What's new for Discoverable Servers?**

Server Web Pages live on the open web and give people a glimpse of what a Discord community is about before they join. They’ve been available to Discoverable Servers for some time, but setup takes a few steps, so not every Discoverable Server has created one. Learn more about [Server Web Pages](https://support.discord.com/hc/en-us/articles/4673515000983-Discord-Server-Web-Pages).

**Starting from November 16, 2026, every Discoverable Server will have a Server Web Page.** If you’re an admin and have already set one up, you don't need to do anything. If you don’t have one and want to get a head start on how your community shows up to the rest of the internet, you can go through the setup process today and publish it in a few clicks. If your moderation team doesn't set one up beforehand, a default page goes live for you on November 16, 2026, using details from your Server Profile. You can edit it whenever you like. Having a Server Web Page is a core part of being a Discoverable Server. If you don't want one, you can always switch back to being a [Community Server](https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types).

**Server Web Pages are also getting more useful.** Until now, your Server Web Page has shown a small description of what your community is about. From November 16, 2026, it may also start showing what your community is *talking* about. Including this helps someone with a question find their way to your community if it already has the answer.

**Channel Summaries**. These show a small slice of what's being talked about in your server, directly on your Server Web Page. These automated summaries focus on active conversations from November 16, 2026, onwards. Admins can change which channels they draw from, curate the summaries that are shown, or turn them off entirely. Usernames and avatars will not be shown in summaries.

![A close-up of what a Conversation Summary would look like on Dead by Daylight’s Server Web Page, showing a few key takeaways and emoji reactions used in the conversation. ](https://cdn.prod.website-files.com/5f9072399b2640f14d6a2bf4/6ad923eeb249958c3f1c2a2c_56222426.png)

**Channel Messages.** From mid-December 2026, answers to questions your members sent in public channels can be found in a web search, in their own words. Server admins decide which channels take part, and server members can choose whether their own messages appear. Usernames and avatars will not be shown alongside these messages.

You can already see an early version of this on a few Server Web Pages. We’ve been piloting Channel Messages with Discoverable game communities, including [NBA 2K](https://discord.com/announcements/941114713402650664), [Rust](https://discord.com/announcements/577855245435142155), and [Dead by Daylight](https://discord.com/announcements/538844350856298526). (During this pilot, all posts were from admins and moderators, not members.)

![A Server Announcement displayed on the Server Web Page for Dead by Daylight.](https://cdn.prod.website-files.com/5f9072399b2640f14d6a2bf4/6ad923eeb249958c3f1c2a2f_b0a76a30.png)

If you're running a community, useful answers to common community questions can show up in web search: how to unlock an easter egg, new builds or strategies, or a boss guide. Someone looking for help will be able to find a real answer from a real person, and can step straight into the conversation that it came from by clicking through and opening Discord.

## **What does this mean for Discoverable Server members?**

Starting mid-December 2026, if a server’s admins allow it, messages from public channels can appear on Server Web Pages and in search results, without usernames and avatars. Messages you sent before then won’t be shown. Channels where content may appear on the web will be labeled, so you know before you send a message.

If you'd rather your messages weren't shown, **you can turn that off today** in [User Settings > Data and Privacy](https://discord.com/settings/data-and-privacy). One switch covers every Discoverable Server you're a part of.

![The new option to “Show my message content from Discoverable channels on web pages,” located in User Settings > Data and Privacy. ](https://cdn.prod.website-files.com/5f9072399b2640f14d6a2bf4/6ad923eeb249958c3f1c2a4c_1b8663b8.png)

We're rolling this out gradually, so it may be a few weeks before the first messages from those channels go live. [Learn more](https://support.discord.com/hc/articles/44302319454359).

## **What can admins do now?**

**Your server controls start rolling out today**, in Server Settings > Web Presence. You can choose which channels take part, or turn them all off.

![The new options for Server Admins to customize their Server Web Page, located in Server Settings > Web Presence. ](https://cdn.prod.website-files.com/5f9072399b2640f14d6a2bf4/6ad923eeb249958c3f1c2a52_29192f9c.png)

**If you don’t change anything, public channels stay on, your Server Web Page goes live on November 16, 2026** (if it's not already published), and **Channel Summaries can start the same day. Channel Messages start rolling out in mid-December 2026.** You can adjust your Channel Summaries and Channel Messages settings before they roll out. And if you'd rather publish your Server Web Page yourself, you can do that today.

See the full details in our [Help Center](https://support.discord.com/hc/articles/44049845164823).

However you set things up, we hope this is a step toward bringing back what made forums great: answers anyone can find, and an open door to the community that wrote them.

## **Frequently Asked Questions**

- **How will I know if I am in a server that allows content to appear on the web?**

  - Discoverable Server admins choose which channels to make available on the web.Those channels will be labeled, so you’ll know before you send a message. As always, you can customize your own privacy choices in your user settings under Data & Privacy.
- **What if I decide later that I don’t want my messages shown on the web?**

  - You can turn off your Channel Messages setting anytime in [User Settings > Data and Privacy](https://discord.com/settings/data-and-privacy). Messages you send after that won’t appear on the web. Messages you sent while it was on stay up unless you delete them from Discord. Messages from before mid-December 2026 aren’t included, regardless of your setting. [Learn more](https://support.discord.com/hc/articles/44302319454359).
- **Does this work the same way in every region or for every user?**

  - In the EU, UK, Canada, Brazil, Australia, and South Korea, the member setting for Channel Messages is off by default given legal restrictions, so members’ messages won’t appear on the web unless they turn it on. Users in the teen age group are excluded completely and cannot enable Channel Messages until they’re an adult. Everywhere else, it’s on unless members turn it off. Other than that default, everything works the same way in every region. [Learn more](https://support.discord.com/hc/articles/44302319454359).
