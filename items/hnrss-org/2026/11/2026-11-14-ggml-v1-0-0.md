## Overview

ggml 1.0.0 prunes the deprecated public API and the legacy `DIAG_MASK` ops, adds configurable YaRN truncation and FP8 support, and brings broad performance work across backends: few-row quantized matmuls and MoE fusion on CUDA/Metal, a Vulkan prefill FlashAttention path, a device-side MoE scheduler on SYCL, decomposed Adreno FlashAttention in OpenCL, new WebGPU kernels, expanded Hexagon op coverage, and scheduler improvements that avoid uploading unused inputs.

### API changes

- Pruned deprecated API and removed the legacy `DIAG_MASK_INF`/`DIAG_MASK_ZERO` ops, bumping the RPC protocol to reject incompatible peers ([llama/29801](https://github.com/ggml-org/llama.cpp/pull/29801), [llama/31946](https://github.com/ggml-org/llama.cpp/pull/31946))
- Added `ggml_rope_set_truncate`/`ggml_rope_get_truncate` to control YaRN correction-bound rounding ([llama/30206](https://github.com/ggml-org/llama.cpp/pull/30206), [llama/30802](https://github.com/ggml-org/llama.cpp/pull/30802))
- Implemented the backward pass for `TRI` ([llama/30712](https://github.com/ggml-org/llama.cpp/pull/30712))
- Added `MUL_MAT` src1 precision tests and gating for `ggml_prec_set_acc` ([llama/31896](https://github.com/ggml-org/llama.cpp/pull/31896), [llama/31851](https://github.com/ggml-org/llama.cpp/pull/31851))
- Bumped the RPC protocol to v9 with faster loading and graceful failure on unreachable endpoints or failed handshakes ([llama/29413](https://github.com/ggml-org/llama.cpp/pull/29413), [llama/30415](https://github.com/ggml-org/llama.cpp/pull/30415))

### Core changes

- Scheduler skips uploading inputs that are not read and prefetches only inputs produced by earlier splits ([llama/31419](https://github.com/ggml-org/llama.cpp/pull/31419), [llama/32100](https://github.com/ggml-org/llama.cpp/pull/32100))
- MoE cache can compute a share of the cache misses on the CPU and copy the results back asynchronously ([llama/30966](https://github.com/ggml-org/llama.cpp/pull/30966))
- Meta backend raises the compute view limit for buffers with few tensors ([llama/31447](https://github.com/ggml-org/llama.cpp/pull/31447))

### Backend changes

#### CUDA

- Added few-row MMQ for batch sizes 2-24 and MMVF for BF16 few-row matmuls ([llama/31533](https://github.com/ggml-org/llama.cpp/pull/31533), [llama/31959](https://github.com/ggml-org/llama.cpp/pull/31959))
- Added OCP FP8 support and fused NVFP4 gate/up matmuls with GLU in MMQ ([llama/28413](https://github.com/ggml-org/llama.cpp/pull/28413), [llama/31296](https://github.com/ggml-org/llama.cpp/pull/31296))
- Extended FlashAttention with an sm70 head-size-256 config and MMA head sizes 40/72 ([llama/27997](https://github.com/ggml-org/llama.cpp/pull/27997), [llama/30285](https://github.com/ggml-org/llama.cpp/pull/30285))
- Improved graph handling: skip compat checks on reuse, re-instantiate on cluster-dim changes, move graph state ([llama/32004](https://github.com/ggml-org/llama.cpp/pull/32004), [llama/31284](https://github.com/ggml-org/llama.cpp/pull/31284), [llama/32001](https://github.com/ggml-org/llama.cpp/pull/32001))
- MoE: skip empty MMQ stream-k tiles, linearize the MoE layout, and sanitize post-bias NaNs ([llama/32067](https://github.com/ggml-org/llama.cpp/pull/32067), [llama/31047](https://github.com/ggml-org/llama.cpp/pull/31047), [llama/31005](https://github.com/ggml-org/llama.cpp/pull/31005))
- Added a debug buffer pool and halved the VMM pool reservation with reserve retries ([llama/31919](https://github.com/ggml-org/llama.cpp/pull/31919), [llama/30542](https://github.com/ggml-org/llama.cpp/pull/30542))
- HIP: use a fixed BLAS workspace and add an MFMA lightning indexer for CDNA2 ([llama/31838](https://github.com/ggml-org/llama.cpp/pull/31838), [llama/29050](https://github.com/ggml-org/llama.cpp/pull/29050))
- Added a d\_state=64 SSM\_SCAN fast path and made radix Top-K deterministic for ties ([llama/31818](https://github.com/ggml-org/llama.cpp/pull/31818), [llama/31084](https://github.com/ggml-org/llama.cpp/pull/31084))

#### Metal
