[![IceWM website logo](https://ice-wm.org/images/logom.jpg "ice-wm.org")](https://ice-wm.org)

IceWM is a window manager for the X Window System. The goal of IceWM is speed, simplicity, and not getting in the user’s way. It comes with a taskbar with pager, global and per-window keybindings and a dynamic menu system. Application windows can be managed by keyboard and mouse. Windows can be iconified to the taskbar, to the tray, to the desktop or be made hidden. They are controllable by a quick switch window (Alt+Tab) and in a window list. A handful of configurable focus models are menu-selectable. Setups with multiple monitors are supported by RandR and Xinerama. IceWM is very configurable, themeable and well documented. It includes an optional external background wallpaper manager with transparency support, a simple session manager and a system tray. IceWM [is available](https://ice-wm.org/status/) on popular Linux distributions like Debian, Ubuntu, Arch, OpenSUSE, Gentoo, Slackware, CentOS, antiX, NixOS and on most \*BSDs.

### Software

IceWM was created by Marko Maček in 1997 using C++. It is now maintained at [Github](https://github.com/bbidulock/icewm).

### Releases

The [latest](https://github.com/ice-wm/icewm/releases/latest) released version is [4.1.0](https://github.com/ice-wm/icewm/releases/download/4.1.0/icewm-4.1.0.tar.lz) (2026-08-06).

### Features

- Easy to use, simple and fast
- Standards compliant [→](https://github.com/ice-wm/icewm/blob/master/COMPLIANCE)
- Fully usable with keyboard
- Alt+Tab window switching
- Efficient resource usage
- Task bar (optional)
- Multiple workspaces
- Fully documented [→](https://ice-wm.org/man/)
- A large number of themes [→](https://themes.ice-wm.org)
- Usable with GNOME and KDE environments
- Regenerates menus when configuration changes
- Support for sound effects [→](https://ice-wm.org/man/icesound)
- Multiple focus modes
- Manual placement of windows option
- Autoraising of windows option
- Tooltips
- Configurable keybindings [→](https://ice-wm.org/man/icewm-keys)
- Supports DockApps in a container
- Tabbed windows

### Themes

IceWM is [themeable](https://ice-wm.org/themes/). The visual appearance of icewm can be changed by a theme, which is a collection of settings and small images. Over 450 themes can be downloaded from [box-look.org](https://themes.ice-wm.org). [Extra](https://github.com/ice-wm/icewm-extra/releases/download/themes/icewm-extra.tar.lz) is a collection of 91 highlights. See `icewm -i list`.

### Install the latest release as follows

```bash
$ wget https://github.com/ice-wm/icewm/releases/download/4.1.0/icewm-4.1.0.tar.lz
$ tar -x --lzip -vpf icewm-4.1.0.tar.lz
$ cd icewm-4.1.0
$ ./configure --prefix=/usr
$ make
$ sudo make install
```

### Install from unreleased development source code

Gettext must be installed.

```bash
$ git clone https://github.com/bbidulock/icewm
$ cd icewm
$ ./autogen.sh
$ ./configure --prefix=/usr
$ make
$ sudo make install
```

If you have cmake, an alternative is:

```bash
$ git clone https://github.com/bbidulock/icewm
$ cd icewm
$ ./rebuild.sh -r --prefix=/usr
$ cd build
$ sudo make install
```

### Install package dependencies

To install all package dependencies in one go use the following script.

```bash
$ wget https://ice-wm.org/scripts/os-depends.sh
$ sudo bash -x ./os-depends.sh
```

Verify package dependencies by:

```bash
$ pkg-config --modversion x11 xext xcomposite xcursor xdamage xfixes xres xrender xrandr xinerama xft fontconfig sm ice sndfile alsa ao gio-2.0 gio-unix-2.0 gdk-pixbuf-xlib-2.0 imlib2 librsvg-2.0 xpm libpng libjpeg
# or simpler:
$ ./rebuild.sh -d
```
