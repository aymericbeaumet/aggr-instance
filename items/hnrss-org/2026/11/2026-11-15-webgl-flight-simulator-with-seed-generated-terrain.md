Controls

|          |                                                                 |
| -------- | --------------------------------------------------------------- |
| Fly      | Left thumb: drag anywhere on the left half (drag down to climb) |
| Throttle | Lever on the right edge (double-tap = idle)                     |
| Flaps    | FLAP + / FLAP − (UP, T/O, LAND)                                 |
| Brakes   | Hold BRAKE                                                      |
| Rudder   | Automatic (the stick steers on the ground)                      |
| Camera   | CAM (chase / cockpit)                                           |
| Bail out | Hold BAIL for a second                                          |
| Pause    | ❚❚ top-left                                                     |
| Tilt     | Pause → Steer by tilting                                        |

|                 |                                            |
| --------------- | ------------------------------------------ |
| Pitch           | W / S or ↑ / ↓ (S pulls up)                |
| Roll            | A / D or ← / →                             |
| Rudder          | Q / E                                      |
| Throttle        | Shift / Ctrl (or 1–9, 0 = full)            |
| Flaps           | F more / V less (UP, T/O, LAND)            |
| Brakes          | B                                          |
| Camera          | C (chase / cockpit)                        |
| Mouse stick     | M toggles                                  |
| Bail out        | X                                          |
| Destination     | ← / → on the menu (Cross-country)          |
| Pause / Restart | Esc or P / R                               |
| Gamepad         | L-stick fly, R-stick X rudder / Y throttle |
