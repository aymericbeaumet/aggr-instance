By The Cognition Team05.13.26

Devin can now spin up an Android Virtual Device (AVD), enabling autonomous development for Android applications.

Until now, Devin could work on Android code, but it could not run and test the app in a local Android environment. With today’s new Android emulator support, Devin can now build and run Android applications directly on its own machine. This gives Devin the Android equivalent of computer and browser use: it can open the app, inspect behavior, reproduce issues, and verify changes in the environment where the application actually runs.

This is available now for teams using Devin. To use it, simply start working on Android applications, then ask Devin to work on your Android app as usual.
