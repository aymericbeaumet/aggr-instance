By The Cognition Team05.05.25

It shouldn't take hours to get up to speed on a new codebase.

That's why we built [Devin Wiki](https://docs.devin.ai/work-with-devin/devin-wiki) and [Devin Search](https://docs.devin.ai/work-with-devin/devin-search), tools that helps developers quickly grok and understand complex code.

Now, we're launching [DeepWiki](https://deepwiki.com/), the free public version of Devin Wiki and Devin Search. Visit the DeepWiki for any repo by replacing github.com with deepwiki.com in the URL.

![DeepWiki: AI docs for any repo](https://cdn.sanity.io/images/2mc9cv2v/production/4aaf250820dd4be1cb4f9cc8413f25f68d0ab415-2916x1908.png?w=1600&fit=max)

We've already indexed over 50,000 of the top public GitHub repos, from the [Model Context Protocol](https://deepwiki.com/modelcontextprotocol/modelcontextprotocol) to [LangChain](https://deepwiki.com/langchain-ai/langchain). Add any public repo for free at [deepwiki.com](https://deepwiki.com/). For private repos, [sign up](https://devin.ai/) for a Devin account.
