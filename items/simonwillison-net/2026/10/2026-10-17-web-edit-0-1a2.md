[web-edit 0.1a2](https://github.com/simonw/web-edit/releases/tag/0.1a2) — Web app for editing files in a folder

web-edit ([previously](https://simonwillison.net/2026/Oct/12/web-edit/)) is my tiny web app for browsing and editing files in a folder. I mainly built it for editing files on different machines via Tailscale.

I added a "copy to clipboard" option for both text and image data. I needed this because I was running pelican prompts on a laptop from my phone (here's [DeepSeek 4.1 Flash 1017](https://tools.simonwillison.net/markdown-svg-renderer?url=https%3A%2F%2Fgist.github.com%2Fsimonw%2Fb1cec9726b6aa62d4de47100f90f0c1a)) and I wanted an easy way to copy the resulting logs into a Gist.
