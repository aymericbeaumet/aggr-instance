**[Python 3.15.0 added to actions/python-versions](https://github.com/actions/python-versions/commit/49858b91c92d27403416ee43117032e91d00ce24)**. Bit of a niche link, but I've been waiting for this for a couple of days - I even [told ChatGPT](https://chatgpt.com/share/6acad42a-2868-83e8-9a16-736f9def2b45) to check for it:

> `Clone https://github.com/actions/python-versions  and git pull once an hour until they add the stable  3.15 - then tell me about it`

Now that this has landed, you can add `"3.15"` to a GitHub Actions testing matrix to run tests against the [new Python 3.15.0 release](https://www.python.org/downloads/release/python-3150/).
