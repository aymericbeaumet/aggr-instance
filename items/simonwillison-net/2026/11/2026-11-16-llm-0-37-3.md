A bug fix release for [LLM](https://llm.datasette.io), mainly to cover a problem with the most recent Homebrew package of the software.

Homebrew now ships the latest SQLite, [3.54.1](https://www.sqlite.org/releaselog/3_54_1.html), which includes [a fix](https://sqlite.org/bugs/info/2026-10-12T13:52:22Z) that [broke LLM's logging code](https://github.com/simonw/llm/issues/1879).

Short version: in SQLite 3.54.0 the following SQL:

```
select json_object('a', (select json_array(1)))
```

Returns this:

```
{"a":[1]}
```

But in 3.54.1 the same query returns this:

```
{"a":"[1]"}
```

According [to D. Richard Hipp](https://sqlite.org/forum/forumpost/dff1a343157e422f):

> That was a bug fix. Per the documentation, (SELECT json\_array(...)) returns SQL text, not JSON. Hence the 3.54.1 behavior is correct and 3.54.0 was a bug.

The workaround looks like this:

```
select json_object('a', json((select json_array(1))))
```
