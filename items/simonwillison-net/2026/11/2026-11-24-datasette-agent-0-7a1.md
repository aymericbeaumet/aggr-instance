[datasette-agent 0.7a1](https://github.com/datasette/datasette-agent/releases/tag/0.7a1) — An LLM-powered agent for Datasette

I small improvement to [Datasette Agent](https://agent.datasette.io/): chat sessions can open an iframe side panel, and that panel can then navigate to different pages. This version improves navigation by fragment hashes, for deeper integration with other Datasette plugins that update fragment hashes when the user interacts with the plugin in a way that changes state.

I built this in order to fix some bugs with the much more exciting [datasette-charts 0.2a0 release](https://simonwillison.net/2026/Nov/24/datasette-charts/).
