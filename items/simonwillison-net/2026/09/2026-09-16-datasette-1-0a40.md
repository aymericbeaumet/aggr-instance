Same security fix as [0.65.5](https://simonwillison.net/2026/Sep/16/datasette-2/), plus some neat new features and bug fixes:

- Plugins can now launch and manage **background tasks** using the new [datasette.add\_background\_task()](https://docs.datasette.io/en/latest/internals.html#datasette-add-background-task) method. Thanks, [Alex Garcia](https://alexgarcia.xyz/).
- I've migrated Datasette to [httpx2](https://github.com/pydantic/httpx2) for features like the internal `datasette.client.get()` method.
- A whole lot of [bug fixes](https://docs.datasette.io/en/latest/changelog.html#a40-2026-09-16), many of them stemming from a recent effort to triage issues for a 1.0 stable release.
