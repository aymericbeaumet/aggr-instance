### Command line

Linux & macOS

## What OONI Probe measures

![](https://ooni.org/install/web@2x.png)

### Discover which websites are blocked

Run OONI Probe to check which websites are blocked in your country.

![](https://ooni.org/install/performance@2x.png)

### Learn how fast your network is

Measure the speed and performance of your network with the NDT test, developed in collaboration with [M-Lab](https://www.measurementlab.net/).

![](https://ooni.org/install/messaging@2x.png)

### Check which apps are blocked

Test WhatsApp, Facebook Messenger, and Telegram to check if they are blocked. Run OONI Probe to check if circumvention tools work on your network.

![OONI Explorer](https://ooni.org/install/explorer-browser@2x.png)
