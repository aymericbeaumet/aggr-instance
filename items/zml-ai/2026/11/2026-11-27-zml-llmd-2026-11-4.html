Inkling 2 Mini, Hy4 Flash, and EmbeddingGemma2, with new drafters and broader quantized inference support.

November 27, 2026 inference / serving / NVIDIA / AMD / Metal / Intel

We are pleased to announce the release of zml/llmd 2026.11.4. This week we are bringing 3 more models:

  • Inkling 2 Mini
  • Hy4 Flash
  • EmbeddingGemma2

Inkling 2 Mini

We are pleased to bring Inkling 2 Mini to zml/llmd.

A 24-layer decoder-only transformer with sparse Mixture-of-Experts (MoE) feed-forward layers. The middle 12 layers run three times with shared weights, giving 48 layer applications per token from 24 layers of weights. In each layer, each token is routed to 8 of 128 experts. Attention is a hybrid of local and global layers. The model is natively multimodal – images are encoded via a vision transformer – with image and text inputs projected into a shared hidden space and processed jointly by the decoder.

What makes supporting this model challenging for heterogeneous architectures is that it’s natively NVFP4 and MXFP8. Thus, as far as we know, we’re the only inference server supporting it on NVIDIA, AMD, Apple Metal, and Intel at the same time. And it comes with native speculative decoding out of the box.

It’s actually a pretty innovative architecture, and we are happy to support it.

All benchmarks are run on the official checkpoint with MTP off.

Hy4 Flash

We are pleased to bring Hy4 Flash to zml/llmd.

Its 42-layer language backbone consists of one dense feed-forward layer and 41 MoE layers, with identity Hyper-Connections (iHC) supporting inter-layer information flow. A vision encoder (adapted from SigLIP2-So400m-Patch16-Res512) is connected to the backbone through an MLP projector. In addition to the backbone, a built-in 5-layer drafter, DFly2 (0.85B parameters), reuses the target model’s KV cache and sparse indices to support long-context speculative decoding at a low, constant cost.

DFly2 support is not yet available but will come in the next release.

EmbeddingGemma2

We are also pleased to bring EmbeddingGemma2 to zml/llmd and in turn add support for the OpenAI-compatible /v1/embeddings endpoint.

This model is available on all platforms.

More speculative decoding options

Qwen3.8 Flash Next now supports speculative decoding via its native MTP drafter.

Cerebras’ DNeo support was added. For now, the only drafter is for Qwen/Qwen3-4B.

DNeo drafts 15 tokens from a single backbone pass for Qwen3-4B in thinking mode. Instead of discarding rejected predictions, it reuses their target-model features as feedback for the next draft.

CUDA 13.5

This release bumps the embedded CUDA runtime to the latest 13.5 release, which brings a number of performance improvements and bug fixes.

Try it today

NVIDIA

docker run -p 8000:8000 --shm-size=256GB --gpus=all -e HF_TOKEN -it zmlai/llmd:cuda \
    --model=hf://thinkingmachines/Inkling-2-Mini \
    --speculative-drafter-model=native

AMD

docker run -p 8000:8000 --shm-size=256GB --device=/dev/kfd --device=/dev/dri -e HF_TOKEN -it \
    zmlai/llmd:rocm \
    --model=hf://thinkingmachines/Inkling-2-Mini \
    --speculative-drafter-model=native

Intel

docker run -p 8000:8000 --device=/dev/dri -e HF_TOKEN -it zmlai/llmd:oneapi \
    --model=hf://thinkingmachines/Inkling-2-Mini \
    --speculative-drafter-model=native

Google TPU

docker run --net=host --privileged -e HF_TOKEN -it zmlai/llmd:tpu \
    --model=hf://Qwen/Qwen3.8-27B

Apple Metal

brew install zml/zml/llmd
llmd --model=hf://thinkingmachines/Inkling-2-Mini --speculative-drafter-model=native
