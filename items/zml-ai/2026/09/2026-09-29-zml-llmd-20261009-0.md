Another week, another release. We’re happy to announce the release of `zml/llmd 20261009.0`, which brings considerable performance improvements across the board.

# Faster Compilation

In this release, we have spent a considerable amount of effort into improving compilation performance. Notably, when in multiple GPU configurations, auto-tunning is now done in parallel across GPUs. This has a significant impact on cold-start performance, as shown below.

This changes impact NVIDIA, AMD, Intel and Apple Metal backends.
