Today we're bringing Grok into Google Workspace. One add-on puts Grok beside the file you have open in Sheets, Slides, and Docs.

Sheets

Ask a question and Grok answers from the spreadsheet itself, citing the cells it used. It writes and fills formulas, inserts charts, and reruns scenarios when an assumption changes, so updating a model no longer means rebuilding it. Every change is a normal edit you can check and undo.

Slides

Grok turns an outline into a working presentation, researching from the web or X and adding diagrams or images where they help. It extends a deck in its existing theme and rewrites titles so each slide makes its point. The result is regular, editable slides, not an export to fix up.

Docs

Grok writes where the writing happens. It turns rough notes into a structured draft with real headings and lists, fixes grammar in place, and keeps style consistent across a long file. With connectors enabled, it can pull from recent emails or files in Google Drive.

Get started

Grok for Google Workspace is a free add-on, and one install from the Google Workspace Marketplace covers Sheets, Slides, and Docs. Also available for Microsoft 365 in Word, Excel, PowerPoint, and Outlook.
