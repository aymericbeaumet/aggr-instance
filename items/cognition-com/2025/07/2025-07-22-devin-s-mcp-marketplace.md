Devin is now Model Context Protocol (MCP) compatible! You can give Devin access to your favorite MCP servers via the new MCP Marketplace.

For example, you can easily configure Devin to:

- dig through Datadog and Sentry logs
- query databases to answer questions, create charts, and other analytics
- create Notion docs, Google Docs, and Linear tickets
- pull in context from and interact with Figma, Airtable, Stripe, Hubspot and a lot more!

For MCP setup tips and more details, please see the [docs](https://docs.devin.ai/work-with-devin/mcp).

Find the [MCP Marketplace](http://app.devin.ai/settings/mcp-marketplace) in Settings.
