We're excited to launch the official DeepWiki Model Context Protocol (MCP) server. Like [DeepWiki.com](https://deepwiki.com/), it's completely free with no login or auth required.

The DeepWiki MCP server provides programmatic access to powerful context-gathering and question-answering tools for all GitHub repos indexed on [DeepWiki.com](https://deepwiki.com/). It includes the following tools: ask\_question, read\_wiki\_contents, and read\_wiki\_structure.

### Getting Started

- Check out the [Devin docs](https://docs.devin.ai/work-with-devin/deepwiki-mcp) for endpoints and setup info for popular clients (i.e. Claude Desktop).
- OpenAI shared examples of using the DeepWiki MCP server with their API. View them [here](https://platform.openai.com/docs/guides/tools-remote-mcp).

### Add Your Repositories

If you want your public GitHub repo to be available via the MCP server, index it at [DeepWiki.com](https://deepwiki.com/). Indexed repositories are accessible through both the MCP server and DeepWiki's site. Don't forget to add a DeepWiki badge to your project's README using the [badge maker](https://deepwiki.com/badge-maker).

To index private repositories, create a [Devin account](https://devin.ai/) and connect your GitHub.

### Supporting Open Source

Through initiatives like DeepWiki and the Devin Open Source Initiative, we're committed to supporting open-source maintainers. If you manage an open-source repository, you can apply for $500 in Devin credits [here](https://form.typeform.com/to/AITkMdpD).
