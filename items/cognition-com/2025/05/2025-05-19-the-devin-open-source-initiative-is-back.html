We're bringing back the Devin Open Source Initiative.

To support the Open Source community, we’re offering $500 in Devin ACUs (credits) to any open source GitHub project with over 100 forks. Projects under the threshold will still be considered.

To be eligible, projects should have an OSI-approved license and be actively maintained.
