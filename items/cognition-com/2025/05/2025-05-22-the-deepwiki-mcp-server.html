DeepWiki MCP Server

We're excited to launch the official DeepWiki Model Context Protocol (MCP) server. Like DeepWiki.com, it's completely free with no login or auth required.

The DeepWiki MCP server provides programmatic access to powerful context-gathering and question-answering tools for all GitHub repos indexed on DeepWiki.com. It includes the following tools: ask_question, read_wiki_contents, and read_wiki_structure.

Getting Started

  • Check out the Devin docs for endpoints and setup info for popular clients (i.e. Claude Desktop).
  • OpenAI shared examples of using the DeepWiki MCP server with their API. View them here.

Add Your Repositories

If you want your public GitHub repo to be available via the MCP server, index it at DeepWiki.com. Indexed repositories are accessible through both the MCP server and DeepWiki's site. Don't forget to add a DeepWiki badge to your project's README using the badge maker.

To index private repositories, create a Devin account and connect your GitHub.

Supporting Open Source

Through initiatives like DeepWiki and the Devin Open Source Initiative, we're committed to supporting open-source maintainers. If you manage an open-source repository, you can apply for $500 in Devin credits here.
